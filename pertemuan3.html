Teks Formatting di HTML

Teks formatting adalah teknik untuk memformat teks agar terlihat lebih menarik dan mudah dibaca.

Teks Tebal di HTML

Gunakan strong atau b untuk membuat teks tebal. Bisa juga digabung tebal miring untuk membuat teks tebal sekaligus miring.

Teks Miring di HTML

Gunakan em atau i untuk membuat teks miring.

Teks Bergaris Bawah di HTML

Gunakan u untuk membuat teks bergaris bawah.

Teks Dicoret di HTML

Gunakan s atau del untuk membuat teks dicoret.

Teks Subscript dan Superscript di HTML

Gunakan sub untuk teks turun ke bawah contohnya H2O, dan sup untuk pangkat contohnya 23 = 8.

Teks Stabilo di HTML

Gunakan mark untuk memberi tanda stabilo atau highlight kuning pada teks.

Teks Kecil di HTML

Gunakan small untuk membuat ukuran teks jadi lebih kecil.

Teks Kode di HTML

Gunakan code untuk menampilkan potongan kode program.

Teks Tombol Keyboard di HTML

Gunakan kbd untuk menandai tombol keyboard, contohnya Ctrl + C lalu Ctrl + V.

Teks Kutipan di HTML

Kutipan pendek pake tag q: Kata dosen, jangan lupa tutup tag HTML kamu.

Kutipan panjang pake blockquote:

Belajar pemrograman web itu harus banyak praktek, jangan cuma dibaca doang slide-nya.

List Tidak Berurutan (Unordered List) di HTML

Gunakan tag <ul> dan <li> untuk membuat daftar pake simbol titik/bullet:

  • HTML
  • CSS
  • JavaScript

List Berurutan (Ordered List) di HTML

Gunakan tag <ol> dan <li> untuk membuat daftar pake nomor urut:

  1. Buka VS Code
  2. Tulis kode HTML
  3. Buka di browser
